# Kemper Rig Organizer — Downloads

Free desktop application for cataloging and organizing Kemper profile files.

**This repository contains public release information and downloadable application packages only. The application source code is maintained separately in a private repository.**

Website: https://kemper-rig-organizer.netlify.app/

## Windows preview

Download the Windows x64 ZIP and its SHA-256 checksum from [Releases](https://github.com/Papacat2/kemper-rig-organizer-releases/releases).

Extract the complete ZIP and open `KemperRigOrganizer/KemperRigOrganizer.exe`. Keep all accompanying files together. The .NET runtime is included. Five manuals are in the `Manuales` folder.

This is a preview, not a stable release. Start with copies of a few profiles and use Copy mode after reviewing the organization plan. The Windows executable is not digitally signed.

## Scope

Search metadata and combine tag filters; save creator and amplifier-brand name mappings; preview folder organization; copy or move files with SHA-256 verification and separate exact duplicates. Original profile metadata is not rewritten. No audio auditioning, sound editing or Profiler control.

No profiles, purchased packs, personal catalogs or user settings are distributed here. macOS builds remain experimental and are not part of this Windows release.
